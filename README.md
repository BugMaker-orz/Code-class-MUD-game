# 纯文字版地牢 MUD（C++ 程序设计实验）

C++17 终端文字地牢游戏（MUD）。纯命令行交互，无图形界面，通过输入 `去 东`、`攻击 史莱姆`、`开宝箱` 等命令游玩。

## 玩法

- 5 层地牢，每层 6 个房间（奇数层横排、偶数层竖排），房间标注起点 / 战斗 / 商店 / 宝箱 / 楼梯 / 魔王
- 回合制战斗（战斗消息实时显示怪物剩余血量）、商店交易、宝箱拾取、NPC 剧情对话
- **双结局**：正常击败魔王 → 勇者结局；击杀向导夺取资源后击败魔王 → 新魔王结局
- **攻击向导**：击杀向导获得强力资源，全地牢向导拒绝对话并咒骂（v2.0）
- **存档/读档**：`保存` / `读取`，写入 save_mud.txt（v2.0）
- **消耗品修复**：满血时使用药水/食物提示无效且不消耗；消耗品用后从背包消失，装备类保留（v2.1）
- **数值平衡**：魔王削弱（攻 12+层→10+层、防 8→7）；升级曲线加快（`等级×100`→`60+等级×30`，1→2 级仅需 90 经验）；读档高经验自动跨级消化（v2.2）
- **装备显示与数值拆分**：攻/防显示为`基础值(+装备加成)`（如`攻 6(+3)`）；状态栏列出当前装备；背包中已装备物品带`【已装备】`标记（v2.3）
- **旧版 MinGW 兼容**：手动补上 `ENABLE_VIRTUAL_TERMINAL_PROCESSING=0x0004`，使旧版 MinGW 下 ANSI 彩色正常（v2.31）
- 全视野，每帧显示：小地图 → 房间描述 → 信息 → 状态
- ANSI 彩色界面，UTF-8 中文

## 构建与运行

```bash
mkdir build && cd build
cmake ..
cmake --build .
./mud_text            # 随机地图
./mud_text 42         # 固定种子，地图可复现
```

要求：C++17 编译器（g++ / clang++ / MSVC）+ CMake ≥ 3.15。

## 目录结构

```
src/
├── text/          # 文字版专属：main_text.cpp（入口）、TextGame.h/.cpp（主控类）
├── core/          # 基础层：GameContext（全局状态）、Entity（实体基类）、Position、TileType
├── character/     # Player、Monster、Npc
├── combat/        # CombatSystem（回合制战斗结算）
├── map/           # Map（瓦片+房间）、DungeonGenerator（地牢生成）
└── item/          # Item、DropSystem（掉落）、ShopSystem（商店）
```
